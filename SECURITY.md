# Security Policy

Cryptographic confidentiality is core to the mission of Nexus Protocol.

## Supported versions

| Version | Supported |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a vulnerability

If you discover a security flaw or a cryptographic weakness in the protocol,
**please do not open a public issue.**

Report it privately through **GitHub Security Advisories** on this repository
(Security → Report a vulnerability), which creates a confidential channel with
the maintainers.

Please include:

- a description of the vulnerability and its impact,
- reproduction steps or a proof of concept,
- affected version(s) and environment.

We aim to acknowledge reports within 72 hours and to ship a coordinated fix as
quickly as the severity warrants. Reporters are credited in the advisory unless
they prefer to remain anonymous.

## Scope

In scope: the protocol specification, the hub, both official SDKs, and the CLI.

Out of scope: vulnerabilities in third-party dependencies (report those upstream),
and issues that require an already-compromised host.
